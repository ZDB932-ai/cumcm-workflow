# 规则、冻结与提交

不在可复用技能中硬编码某届比赛的官方日期、平台操作或 AI 声明要求。
历史对话中的赛程和规则是待核实材料，不直接作为当前赛事事实。

## 1. 规则核实与 AI 记录

从用户提供的当届正式文件或可访问的主办方官方来源核实：
开始/截止与时区、各项上传/摘要或校验码步骤、文件格式/命名、
匿名要求、允许资料与协作方式、AI 使用及披露要求、学校/赛区补充事项。
记录来源地址/文件、发布/访问日期、适用范围及条款定位，存 Fact Evidence。
来源冲突时区分全国、赛区、学校与不同提交流程；不能把单一截止套用于所有步骤。

工具可以核实则先查，不把可查询的事实一律推给用户。
无法访问或规则未明确时列出具体缺项，暂停依赖它的不可逆操作，
继续本地准备。未知不等于禁止，也不等于默认允许。
外部 Agent 上传、联网研究和跨队交流须按适用规则分别检查。

若使用 AI，随实际使用记录工具/版本（未知则注明）、时间、用途、
提示/输出位置、采用范围、人工修改与验证者/验证依据。
可记录在 `logs/ai-usage.md` 或赛事指定表中，必要的完整记录另存，不塞入 STATE。
按正式要求生成声明/详情材料，不能把通用示例称作官方模板。
Agent 无法替人声称“已人工审核”。
人工核验记录关联实际核验者、产物版本、范围、反馈及未通过项；仅有“已核验”
占位或 Agent 自填不满足要求。声明由真实用途与采纳记录汇总，不用模板代替事实。

首次有可导出的论文/结果表时做一次小型工具链检查：可打开、字体/公式、
模板结构、公式缓存（若适用）与数值映射。缺项尽早处理，不等最终打包才发现。
具体格式交给当前可用的文档/表格/PDF 工具；工具缺失时说明所缺检查，不冒称已预览。

## 2. 冻结协议

截止临近只触发收敛建议和风险评估，Freeze 是独立控制动作。
进入 G7 前：稿件及关键证据已审核、无阻断问题、有可访问的冻结产物、
提交检查已完成、符合用户选择或已确认的冻结计划。
若用户要提前锁定部分产物，可做 scoped snapshot，但不能虚报全题 G7 通过。

冻结时生成唯一 Checkpoint 和清单：
文件/版本/hash、论文导出、代码/数据依赖、验证记录、已知局限、恢复办法。
设置 STATE.freeze.active 和 checkpoint 指针；不是只把 Pressure 改成 FREEZE。
“全部 PAPER_READY”或“剩余少于 12h”不自动冻结。

冻结后默认仅做必要勘误、图表修正、摘要/格式检查和提交准备。
重大更改按 [user-intent.md](user-intent.md) 的风险确认，保留旧包再建立新版本。
Critical 错误不能因 Freeze 而忽略，普通小修也不需要一律申请 Critical Override。
每次改变待提交文件后重新导出、检查和计算所需校验值，不继续使用旧 hash。
修订生成新快照，原快照保留；没有真实副本时不能承诺“30 分钟必能回滚”。

## 3. 提交前检查

按实际依赖清单组织支撑材料：必要完整源码、输入放置说明、所需外部资料、
结果与复现入口。不要把整个研究目录原封不动复制；旧备份、重复图、调参缓存按
用途筛选。原始题面数据、附录代码、文件大小等以当届正式规范为准，不把某次
“只放核心代码”“附录若干页”的偏好当作合规依据。
可重建缓存只有在重建入口及依赖已核验后才可省略；包内相对路径与外部依赖明确。
先做导入/短例检查，再按授权完成必要复现；源码齐全、导入成功、小样本通过和
全量结果复现分别报告。可用 [project-checks.md](project-checks.md) 检查声明清单，
但它不自动发现动态代码依赖、核对论文数字或运行包内程序。

1. 按适用规则核对论文、支撑代码/数据、AI 材料和命名/大小/匿名要求。
2. 打开最终导出文件，检查文字、公式、图片、页码、引用及缺项标记。
3. 复核核心论断与结果；确认提交的是冻结/修订清单中的同一版本。
4. 按官方要求计算校验值并记录算法、文件和时间，不自行假定固定算法。
5. 留出上传/重试缓冲，准备用户需要完成的账号和确认操作。

本地打包或生成校验值不等于已经上传。没有用户对具体平台/目标/材料的授权，
不自动上传或最终提交；有授权仍需遵守工具确认和环境权限。

## 4. 回执与完成

逐项记录：本地已准备、已上传待确认、已确认提交；每个适用步骤分别核验。
只有全部必需步骤都有平台回执或用户提供的明确提交证据，才能标记 G8 通过。
无回执时报告 pending/unknown，不把超时当成功，不盲目重复可能已有副作用的提交。
最终记录时间、目标、版本/hash、回执位置和未完成事项。
完成后保存提交快照；后续修订创建新版本，不改写原提交记录。
